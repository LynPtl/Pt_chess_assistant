# 任务交接：截图直接导入国际象棋分析界面

## 1. 任务一句话
实现一个本地工作流：用户对国际象棋棋盘截图后，系统自动/半自动将截图识别为 FEN，并把 FEN 导入本地 GUI 分析界面，供 Maia 3 或 Stockfish 等 UCI 引擎分析。

## 2. 背景
- Maia 3 是 UCI 引擎，本身不处理图片，只接收 FEN/走法。
- 因此“截图直接拉进分析界面”的本质是：
  `截图 -> 棋盘识别 -> FEN 字符串 -> 导入 GUI -> 引擎分析`
- 目标不是修改 Maia 3，而是做一个截图到 FEN 的桥接工具/流程。

## 3. 目标
### P0 必须完成
- 支持从本地截图文件或剪贴板图片生成 FEN。
- 支持人工核对识别结果，避免错误局面进入分析。
- 支持将 FEN 快速导入至少一个本地 GUI 分析软件。
- 在本地 GUI 中可调用 Maia 3 或 Stockfish 分析该局面。

### P1 建议完成
- 提供全局热键：截图后一键识别并复制 FEN。
- 自动模拟 GUI 的“从剪贴板读取 FEN”快捷键。
- 提供简单日志，记录每次识别出的 FEN 和置信度/警告。

### P2 可选
- 支持批量图片识别。
- 支持监听剪贴板图片变化并自动识别。
- 支持多平台：Windows / macOS / Linux 至少一个主平台，其他平台给说明。

## 4. 非目标
- 不训练新的棋盘识别模型。
- 不修改 Maia 3 源码。
- 不实现在线网站爬虫或破解。
- 不保证所有非标准棋盘主题 100% 识别；必须保留人工核对环节。

## 5. 推荐技术路线
### 路线 A：最快 MVP，手动半自动
1. 用户截图。
2. 打开浏览器工具 `fenshot` 或本地工具识别为 FEN。
3. 复制 FEN。
4. 在 Arena 中按 `F6`，或菜单 `Position -> Get FEN from Clipboard` 导入。
5. 选择 Maia 3 / Stockfish 分析。

适用：快速验证，不需要写代码。

### 路线 B：本地脚本自动化，推荐交给 agent 实现
1. 监听截图文件或剪贴板图片。
2. 调用本地识别工具生成 FEN：
   - 优先尝试 `chessimg2pos`（Python，命令行）。
   - 备选 `chess-scan`（Node.js）。
   - 如果安装困难，调用 `fenshot` 的本地/在线页面作为兜底。
3. 用 `pyperclip` 将 FEN 写入剪贴板。
4. 模拟 GUI 快捷键（如 Arena 的 `F6`）导入局面。
5. 输出日志并提示用户核对。

适用：接近“截图直接拉进分析界面”的体验。

## 6. 环境与依赖
请 agent 先确认：
- 操作系统：Windows / macOS / Linux
- Python 版本
- 是否已安装 GUI：Arena / Scid / Nibbler 等
- 是否已安装 Maia 3 或 Stockfish
- 是否允许安装 Python 包和模拟键盘输入

- Nibbler 等 UCI GUI：粘贴 FEN 或通过支持 FEN 的导入入口加载。

## 10. 风险与注意事项
- 棋盘识别可能出错，尤其是非标准棋子主题、翻转棋盘、低分辨率、遮挡、坐标缺失。必须人工核对。

- 不要默认开启全自动导入；建议先显示 FEN 并等待确认。
- 第三方工具许可证需记录，优先选择开源工具。
